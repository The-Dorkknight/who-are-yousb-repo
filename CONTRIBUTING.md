# Contributing

Bug reports and pull requests are welcome. **The project is a work in progress, so bugs are expected.**

- **Bug?** Use the bug-report form. Include your distro, Python version, the command you ran, and the output. For hardware
  issues, `python3 whoareyousb.py list --detail` output is very helpful.
- **Real hardware results** (works / doesn't work on your cable, phone or scanner) are the most valuable thing you can send.
- **Code:** keep it a single file using only the standard library; no network calls or trackers. Anything that changes the
  system must be opt-in and listed in [HOW_IT_WORKS.md](HOW_IT_WORKS.md).
- Please don't attach private captures: they can contain serial numbers or your data.

By submitting a contribution you agree it can be distributed under this project's licence (PolyForm Noncommercial 1.0.0)
and that you have the right to contribute it.
