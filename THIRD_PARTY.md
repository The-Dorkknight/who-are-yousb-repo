# Third-party software

The [PolyForm Noncommercial licence](LICENSE.md) covers **only the code in this repository**.

Who are yoUSB? is a single Python file using only the standard library. It **calls** (but does not bundle) these programs if
they are installed, each under its own licence: `tcpdump`/`dumpcap` (Wireshark), `adb`, `ip`/`ping` (iproute2, iputils),
`pkexec` (polkit), `journalctl`/`dmesg`, and `usb.ids` (linux-usb.org). Optional tkinter comes with Python.

The caterpillar artwork and icons are the author's own. The masked-bandit icon is original.

Product names are used only to describe compatibility.
